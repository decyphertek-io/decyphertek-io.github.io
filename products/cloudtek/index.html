App Features

CloudTek is a mobile app for managing cloud infrastructure across AWS, Azure, and GCP. Launch, start, stop, reboot, or delete virtual machines, manage firewalls and networking, and SSH into any VM from a built-in terminal — all from your phone. A Rust core talks directly to cloud provider APIs over TLS 1.3 with certificate pinning, and credentials are protected with the Android Keystore.

VM Management

  • Launch, start, stop, reboot, delete VMs
  • AWS, Azure, and GCP in one app
  • Marketplace and custom image management
  • Activity dashboard with costs

Security & Access

  • Built-in SSH terminal
  • Credential manager (Android Keystore)
  • TLS 1.3 with certificate pinning
  • Firewall and security group management
